# Endless DJ factory role one-shots

These 28 original mono, 48 kHz WAV files provide four stable song-selected
variants for each non-riser sampler role:

- percussion accent
- alternate percussion
- short fill
- long fill
- impact
- vocal/FX stab
- drop accent

Run `node tools/generate_factory_one_shots.js` from the repository root to
reproduce the exact files. Their use and distribution follows the repository's
license.
