# Endless DJ factory role one-shots

These 28 original mono, 48 kHz WAV files provide four stable song-selected
variants for each non-riser sampler role:

- percussion accent
- alternate percussion
- short fill
- long fill
- impact
- vocal/FX stab
- drop accent

Run `node tools/generate_factory_one_shots.js` from the repository root to
reproduce the exact files. Their use and distribution follows the repository's
license.

Every WAV in these seven folders is original project material with origin
`Endless DJ procedural factory generator` and license `repository license`.
`lib/sample_library.lua` assigns every individual file a stable ID, role,
energy, genre-affinity tags, processing capabilities and vocal occupancy.
Variant 1 is classic/club, variant 2 organic/soulful, variant 3 dark/digital,
and variant 4 rave/aggressive. This generated catalog is the authoritative
per-file provenance and selection manifest.
